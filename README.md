# Барбершоп «Цех» — сайт с онлайн-записью

Четвёртый проект в портфолио, и первый — под реальную задачу малого бизнеса. Хотел сделать то, что барбершопы, салоны и студии заказывают чаще всего: понятный сайт с ценами и нормальной онлайн-записью. Бизнес выдуманный, но сайт полностью рабочий как шаблон.

**Посмотреть:** https://azer1xxx1337.github.io/barbershop/

## Что тут есть

- Вёрстка карточками (bento) и анимированный барбер-столб в логотипе.
- Плашка «Открыто / Откроемся в 10:00» — зависит от текущего времени.
- Карточка «Ближайшее свободное окно» сама находит первый свободный слот.
- Прайс по вкладкам: стрижки, борода, комплексы. Кнопка «Выбрать» сразу подставляет услугу в запись.
- Мастера с нарисованными портретами (SVG), без фото — легко заменить на снимки клиента.
- Запись в 4 шага: услуга → мастер → дата и время → контакты. Занятые слоты зачёркнуты, у мастеров свои выходные, «Любой мастер» подбирает первого свободного. Телефон форматируется при вводе, справа — итог записи с ценой.
- Вопросы-ответы, схема проезда на SVG, часы работы с подсветкой сегодняшнего дня.
- Светлая и тёмная тема, адаптив под телефон.

## Как сделано

Один `index.html`: HTML, CSS и чистый JavaScript без фреймворков и библиотек. Расписание занятости генерируется детерминированно, поэтому выглядит «живым», но не меняется при перезагрузке.

## Запустить у себя

Открыть `index.html` в браузере.

## Важно

Бизнес, адрес, мастера и цены выдуманы. Запись никуда не отправляется — для реального клиента сюда подключается отправка заявки (например, в Telegram или CRM).
